MODULE DETAILS:

MODULE 1: Google Sheets Watch Trigger
─────────────────────────────────────
Type: Trigger
Platform: Google Sheets API
Function: Monitor for new rows
Configuration:
├─ Sheet: "Get Your Free Marketing Consultation (Responses)"
├─ Sheet ID: "Form Responses 1"
├─ Action: Watch for new rows
├─ Poll interval: Real-time
├─ Fields captured:
│  ├─ Timestamp
│  ├─ Full Name
│  ├─ Email Address
│  ├─ Business Name
│  └─ What do you need help with?
└─ Execution limit: 10 rows per trigger

Output to Next Module:
{
  "timestamp": "2026-06-28 14:35:42",
  "full_name": "Rajesh Kumar",
  "email": "rajesh@techstartup.io",
  "business_name": "TechStartup India",
  "need_help": "Lead generation automation"
}

ERROR HANDLING:

Scenario: Sheet connection fails
├─ Status: Red ❌
├─ Action: Auto-retry after 30 seconds
├─ Retry count: Up to 3 times
└─ If fails: Log in Make.com & email admin

Scenario: Email send fails
├─ Status: Red ❌
├─ Action: Auto-retry after 5 minutes
├─ Retry count: Up to 5 times
├─ Common causes:
│  ├─ Gmail quota limit hit
│  ├─ Invalid email format
│  └─ Gmail connection expired
└─ Solution: Check Make.com logs

Scenario: Success
├─ Status: Green ✅
├─ Email sent in 30 seconds
├─ Sheet updated
└─ No action needed
